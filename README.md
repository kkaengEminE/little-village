# 작은 하루 — 웹 플레이 MVP

비공개 로컬 플레이용. 설치할 패키지 없이 Canvas 2D와 HTML로 동작합니다.

## 실행

`start.command`를 실행한 뒤 브라우저에서 http://127.0.0.1:4178 을 엽니다. Python 3가 필요합니다. 또는 이 폴더에서:

```sh
python3 -m http.server 4178 --bind 127.0.0.1 --directory dist
```

서버 실행 중에만 주소에 접속할 수 있습니다. 외부에 배포하지 않았습니다.

## 조작

- WASD / 방향키 / 바닥 클릭: 이동 (WASD는 한글 입력 상태에서도 작동)
- E: 가까운 대상과 상호작용, 잡초 채집
- Space: 가까운 몬스터와 조우 / 시험에서 뽑기·전달
- Shift + 이동: 빠른 걸음
- I 가방 / C 옷장 / B 교재 / M 지도
- 시험: A·D 또는 좌우 방향키로 줄 선택, Space 뽑기·전달, S·아래 방향키 보존·넘기기
- 작은 화면에는 터치 이동과 행동 버튼 표시

## 구현된 범위

- 카메라 추적, 깊이 순서 가림, 건물·나무 충돌, 걷기·작업·공격 애니메이션
- 회색 주민, 장비 레이어(머리띠·작업복·가방), 간단한 앞·뒤·옆 방향 표현
- 제초 5개 의뢰 및 보수 정산. 신규 토벌 수주는 후속 퀘스트 출정 모드로 보류; 이전 저장의 진행 중 토벌 의뢰는 완료 가능
- 몬스터 접근 시 턴제 전투: 일반 공격·강공격·방어·도시락·확정 도망. 적의 다음 공격 예고, 승리 보상 20코인+증표, 패배 시 소지품 보존 및 귀환
- 음식·옷·찻잔 구매, 도시락 나누기, 무료 수프, 수면 및 다음 날
- 제초/아르바이트 5~3급 시험, 무제한 연습, 합격·실수·시간 초과 판정
- 제초 합격 후 보수 상승, 아르바이트 합격 후 모의 근무
- 브라우저 localStorage에 캐릭터 위치·자원·의뢰·장비·급수 저장

맵의 개별 잡초와 몬스터 상태는 새로고침하면 재생성됩니다. 캐릭터 진행은 유지됩니다. 브라우저 저장 삭제 시 진행도 삭제됩니다.

## 아직 없는 것

술 시험, 카드 짝맞추기/두더지잡기 종목, 주민 괴물화 사건, 던전 확장, 고급 난이도, 정교한 방향별 스프라이트는 후속 범위입니다. 플레이어 괴물화 및 강제 엔딩은 없습니다.

## 구조

- `dist/index.html`: HUD와 모달
- `dist/style.css`: 반응형 UI
- `dist/battle.js`: 조우와 턴제 전투 상태·화면·보상
- `dist/game.js`: 월드·렌더링·입력·경제·시험·저장
- `dist/assets/meadow.png`: 생성한 필드 배경
- `tests/game.test.cjs`: 게임 흐름 검증용 Node VM 테스트

검증: `node tests/game.test.cjs`

추후 Unity 이식 시 시험 규칙·경제 값·월드 배치를 데이터로 분리하고 입력/렌더링을 교체할 수 있습니다. 현재 웹 코드는 Unity 프로젝트가 아닙니다.

## 보스 토벌 (실시간)

일반 필드 조우는 턴제, 토벌 담당 갑옷 씨에게 받는 특별 의뢰는 독립 보스방 실시간 전투입니다.

1. 마을 북동쪽 토벌 담당 갑옷 씨에게 잎뿔 괴수 / 돌껍질 괴수 중 하나를 수주합니다.
2. 북쪽 토벌의 문에서 출정: 하루 한 번, 행동력 20. 취소·실패도 그날 기회를 사용합니다.
3. WASD 이동 / J 또는 마우스 클릭 공격 / Space·Shift 회피 / F 도시락. 공격·회피 각각 행동력 1. 음식·수면으로 회복합니다. 이동은 무료입니다.
4. 노란 표시 부위를 때리면 부위 파괴. 잎뿔은 돌진 속도 감소, 돌껍질은 탄환 수 감소.
5. 승리 보상은 즉시 한 번 지급됩니다. 남쪽 열린 출구 가까이에서 E를 눌러 직접 귀환합니다.
6. 체력이 소진되거나 좌상단 구조 요청을 확인하면 헬리콥터 구조 애니메이션 뒤 게이트로 귀환합니다.

우상단 전투 조정 메뉴: 크기, 공격 속도, 최대 HP, 피격 배율, 피해, 이동 속도; 공격·이동·판정표시·무적 스위치; 내 HP/보스 HP·부위 초기화. 설정 숫자는 브라우저 저장에 남습니다. HP·부위 초기화는 전투 중에만 가능하며 승리 보상 재지급을 막습니다.

보스방에서 새로고침하거나 브라우저를 닫으면 해당 출정은 중단됩니다. 이미 소비한 하루 기회·행동력은 유지하며 게이트 앞에서 재개합니다.

`dist/hunt.js`에 보스방, 조정값, 실시간 전투, 구조 연출이 분리되어 있습니다.
